TROUBLESHOOTING
================================================================================

PROBLEM: PostgreSQL won't start
SOLUTION: Check Windows Services
  services.msc → postgresql-x64-18 → Start

PROBLEM: Port 3779 already in use
SOLUTION: Find and kill the process
  netstat -ano | findstr :3779
  taskkill /PID <PID> /F

PROBLEM: Backend fails to connect to database
SOLUTION: Verify connection string in main.go
  Connection should be: postgres://postgres:admin123@127.0.0.1:3779/geomobile137?sslmode=disable

PROBLEM: Frontend won't load
SOLUTION: Check backend is running
  curl http://localhost:8080/health
  If fails, restart backend

PROBLEM: npm install fails
SOLUTION: Clear cache and reinstall
  cd frontend
  npm cache clean --force
  rm -r node_modules package-lock.json
  npm install

PROBLEM: "File not found" errors
SOLUTION: Ensure you're in the correct directory
  cd F:\geomobile137
  Then run commands

For detailed troubleshooting, see: PHASE_1_COMPLETION_FINAL.md
